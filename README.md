# AbacusWeb - Online Abacus Course

An interactive online course for students to learn abacus and develop mental math skills.

## Features

- **Interactive Abacus**: Click on beads to practice number representation
- **Structured Lessons**: Learn from basics to advanced calculations
- **Practice Exercises**: Test your skills with guided exercises
- **Responsive Design**: Works on desktop and mobile devices

## How to Use

1. Open `index.html` in your web browser
2. Read through the lessons to understand abacus basics
3. Use the interactive abacus to practice
4. Click on beads to move them (upper bead = 5, lower beads = 1 each)
5. Try the practice exercises to test your understanding

## Abacus Basics

- **Upper Bead (Heaven bead)**: Represents 5 when moved down
- **Lower Beads (Earth beads)**: Each represents 1 when moved up
- **Columns**: Each column represents a place value (ones, tens, hundreds, etc.)

## Course Content

1. Introduction to Abacus
2. Basic Number Representation
3. Addition Techniques
4. Subtraction Methods

## Benefits

- Improves concentration and focus
- Enhances mental calculation speed
- Develops logical thinking
- Boosts memory and visualization
- Builds confidence in mathematics

Simply open `index.html` in any modern web browser. No installation required!
